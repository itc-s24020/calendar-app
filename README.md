# 📅 Calendar App

シンプルで使いやすいWebカレンダーアプリケーション。予定の管理をブラウザ上で行えます。

## 🎯 機能

- **月ごとのカレンダー表示** — 月単位でカレンダーを表示
- **月移動** — 前月・次月ボタンで簡単に月を移動
- **今月表示** — ワンクリックで今月に戻る
- **予定管理** — 各日付に予定を追加・編集・削除可能
- **予定の時刻指定** — 予定に時刻を設定可能
- **データ保存** — 予定はブラウザのlocalStorageに自動保存
- **当日表示** — 今日の日付は朱印で目立つように表示

## 🚀 使い方

### 起動方法

```bash
npm install
npm run dev
```

ターミナルに表示されたURLをブラウザで開いてください。

### 操作方法

1. **月を移動する** — 「← 前月」「次月 →」ボタンで月を切り替え
2. **今月に戻す** — 「今月」ボタンをクリック
3. **予定を追加する** — カレンダーの日付をクリックしてモーダルを開く
4. **予定を入力** — 日時と内容を入力して保存
5. **予定を削除** — モーダルから削除ボタンで削除

## ⚙️ 設定

`app/config.js` で以下の設定が可能です：

- `rangeInMonths` — 表示できる年月の上下限範囲
- `maxSchedulePreview` — 各日付に表示する予定の最大数

## 📝 技術仕様

- **フロントエンド** — Vanilla JavaScript (ES6+)
- **スタイリング** — CSS
- **データ保存** — ブラウザのlocalStorage
- **開発サーバー** — Node.js
